# Feature Frank

Engineer-side skills for closing the loop on shipped work. Feature Frank is the engineer who picks up PM Penny's feature issues, builds them, ships them — and, critically, learns from the feedback that comes back.

## Skills

- **feature-frank-pr-feedback** — work through review comments on a PR: understand what each comment is saying, diagnose *how* the mistake got through (and what tooling change would have caught it), and either patch the code, push back with a reply, or skip. In-repo tooling updates (AGENTS.md / CLAUDE.md) apply automatically; outside-repo changes (gstack skills, user-global CLAUDE.md) require explicit approval.

## Philosophy

Every review comment is signal. The cheapest way to get better at shipping is to treat feedback as curriculum — fix the code now, and capture the rule that should have caught it next time. Feature Frank compounds that learning into the user's actual tooling so future sessions don't repeat the mistake.
